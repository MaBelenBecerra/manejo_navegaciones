# Manejo_navegaciones# Manejo de Navegaciones - Flutter

Aplicación Flutter que implementa navegación entre pantallas utilizando:
- Rutas nombradas
- Paso de argumentos
- Navegación asíncrona (push / pop)

## Features
- Arquitectura limpia (domain + presentation)
- UI estilo coquette
- Tipografías personalizadas
- Manejo de assets (imágenes)

## Cómo ejecutar
flutter pub get
flutter run
